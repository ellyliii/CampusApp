# CampusApp

Campus App on opiskelijoille suunnattu sovellus kampuksen tapahtumien seurantaan.

## Ominaisuudet
- Tulevien tapahtumien selaaminen
- Tapahtumiin ilmoittautuminen
- Omien ilmoittautumisten tarkastelu
- Palautteen antaminen tapahtumista

## Projektinhallinta
Työtä hallitaan Jirassa (projekti CAMP). Jokainen branch ja commit
sisältää Jira-tehtävän tunnuksen.
